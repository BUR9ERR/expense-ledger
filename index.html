导入账单

怎么导出
微信：我 → 服务 → 钱包 → 账单 → 右上角 ··· → 下载账单 → 用于个人对账
支付宝：我的 → 账单 → 右上角 ··· → 开具交易流水证明 → 用于个人对账
记得勾上「展示交易对方信息」和「展示商品说明信息」。收到的 zip 用邮件里的密码解开，取出里面的文件就行——微信给的是 Excel（.xlsx），支付宝给的是 CSV，两个都直接选进来，不用自己转格式。
分类猜得不准？
导入时会按关键词猜分类。想让它更准，可以往 assets/分类词库.js 里加你常去的店名， 改完刷新页面即生效——具体怎么写，那个文件开头有说明。

疑似转账

这些账目的备注里有「转账 / 还款 / 提现 / 理财」这类字眼， 很可能只是钱在自己账户之间搬，不该算作支出。勾上要改的，点底下的按钮一次性标成 不计收支——分类不变，只是不再进本月支出、日均、预算和年度报告。

分类管理

分类可以自己加、改名字和图标。归档是不再出现在「记一笔」和筛选里， 但历史账目照旧显示——不想删掉旧账的痕迹就用归档。
新增分类

历史版本

电脑上每次保存账本前都会自动留一份（在 data/backups/）。 误删、改错了想退回去，就在这里挑一个时间点恢复。 恢复会把账本整体换成那一刻的样子——动手之前程序会先把「现在」这一份也留档，所以恢复本身也能再退回来。

自动分类规则

导入微信 / 支付宝账单时，备注里包含下面这些关键词的账目会直接归到你指定的分类。 你在流水里改过某笔导入账目的分类，程序会自动把商户名记成一条规则（排在前面、优先命中）。 规则的优先级高于内置词库。
新增规则

周期记账

每月到日子自动帮你记一笔（比如房租、话费、会员）。当天打开记账本时补记， 同一个月只补一次，删掉的当月不会再来。月末会自动回退：模板写 31 号， 2 月就在 28 号（闰年 29 号）补，不会因为那个月没有 31 号而漏掉。
新增模板

数据体检

只找出可疑的账目给你确认，不会自动改任何数据。
